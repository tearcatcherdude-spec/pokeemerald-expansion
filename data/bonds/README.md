# Emerald companion design handoff

Start with Emerald-Companion-Bonds-Design.md. It contains the design, 50 proposed events, explicit meeting points, EXP rules, reward tables, integration cautions, and a message to paste into the main conversation.

bond-events-draft.json contains the same 50 event records for planning/import. It is not executable game data. All marker_tile values are null until the implementing conversation verifies safe map placement.

CURRENT_EMERALD_STATE.md is the November 8 context snapshot, not a live build-status claim.

Brainstorming only. No game files, branches, PRs, or builds were changed by creating this package. Exact ages, preferred gift lists, event dialogue, finalized battle teams, tile coordinates and save migration remain implementation/review work.
